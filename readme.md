# git-practice

Personal repo for practicing core Git skills — commits, branching, merging, conflict resolution, and reset.

## What's in here
- Basic commit history and workflow practice
- Branching and merging (3 branches, each with a different change)
- Deliberate merge conflicts (same line edited on two branches, resolved manually)
- git reset practice (soft/mixed/hard)
- Full PR cycle: branch → commit → push → PR → review → merge → delete → pull

## How to run
Clone it, check the branch history with `git log --oneline --graph --all`.

## What I learned
- How branching and merging actually work under the hood
- The difference between reset --soft, --mixed, and --hard
- How to resolve a merge conflict by hand
- The full PR workflow used on real teams
